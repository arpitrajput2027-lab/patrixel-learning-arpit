# Random Quotes API Project

A simple Python project that fetches random quotes from a public API and saves them to a CSV file.



## How to Run
1. Install requests: `pip install requests`
2. Run the script: `python main.py`

## Features
- Fetches quotes using a public REST API
- Cleans extra spaces using `strip()`
- Saves quotes to CSV
- Handles basic API and file errors
