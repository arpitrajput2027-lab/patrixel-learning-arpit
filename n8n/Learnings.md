# n8n Learnings

## Weather Alert System
- Schedule a workflow to run daily.
- Use an HTTP Request node to get weather data from an API.
- Use an If node to check whether the temperature is above 35°C.
- Send different email alerts based on the condition.

## AI Candidate Analysis
- Collect candidate details and a PDF CV with a form.
- Extract text from the PDF and ask an AI model to structure the information.
- Use an output parser to return consistent fields.
- Save the results to Google Sheets.
- Use synthetic CVs for demos; AI scores should not make hiring decisions.
